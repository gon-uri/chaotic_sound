# Integration resolution: how many RK4 steps per period?

Script: `lab/scripts/studies/resolution.py` (run from `lab/` with
`caffeinate -is uv run python scripts/studies/resolution.py`; 208 s wall on 4 cores).
Numbers: `lab/outputs/studies/resolution/results.json`. Figures (regenerated by the script, gitignored):
`short_horizon_error.png`, `long_run_errors.png`, `envelope_default.png` in the same folder.

## Question

The catalog sets `steps_per_period = 256`: h_max = P_min/256, where P_min is the shortest P(u) over
the range. Is that needed, sufficient or overkill? "Good enough" means that, compared with a
reference integration:

- pitch error below 1 cent;
- σ error below 0.5 % for every audible variable;
- spectral envelope of the heard variable within 1 dB up to 20 f₀.

## Method

- **Systems and points.** All five catalog systems, at u = 0, at the default and at u = 1.
- **Definition of N.** N is the number of steps per period *of that knob position*: h = P(u)/N, with P(u)
  from the catalog. In the engine h ≤ h_max = P_min/N_cat. The effective resolution is therefore
  N_eff(u) = n_sub·fs/f₀ ≥ N_cat·P(u)/P_min ≥ N_cat at every u and every note, with equality only
  at the shortest-period u. This makes a requirement "N ≥ N_min at all three u" a requirement on
  N_cat.
- **Resolutions.** N ∈ {16, 32, 64, 128, 256, 512}, against a reference N = 2048 (16384 for (a)).
- **(a) Short horizon.** We start from 64 points on the attractor, integrate exactly one period,
  and report the RMS state error in units of each variable's σ.
- **(b) Long runs.** We run 8 realizations per N (16 for Thomas and Duffing, which converge slowly),
  each 10 000 periods long after a 50-period transient.
  - Initial conditions are points 41 periods apart on one long N = 2048 trajectory, plus a seeded
    1e-6·σ kick (spec §4.2 step 9). The same initial condition is used for every N.
  - The kick is needed. Without it, the N = 2048 runs replay the seed trajectory bit for bit, the
    "independent" references are shifted copies of one record, and a common offset appears in
    every comparison. A first run had exactly this problem; it was discarded.
  - Records are kept at S = min(N, 64) samples per period, and the reference is decimated to the
    same S. The engine never takes a step longer than one sample, so this matches what it produces.
  - Measured on each record:
    - the period, with the catalog's method (peak centroid; return time for Thomas; exact drive
      period for Duffing), on the catalog's tuning variable;
    - σ of every audible variable;
    - the prominence;
    - the power of the heard variable in 1/3-octave bands from 0.5 f₀ to 20 f₀ (Welch, 128 periods
      per segment).
  - Pitch error = 1200·log₂(P_ref/P_N): the shift of the heard note, because the engine tunes with
    the catalog P.
  - Two exclusions from the envelope test:
    - Bands weaker than −90 dB relative to the variable's total power are not judged. At the
      spec's −12 dBFS RMS they lie below −100 dBFS.
    - Bands are only judged below 0.8 × the Nyquist frequency of the step grid. N = 16 and 32 are
      therefore checked only up to 5 f₀ and 10 f₀. In the engine a note with N_eff that small has
      no harmonics above N_eff/2 below fs/2 anyway.
- **Bias estimate.** For each metric:
  - the direct paired difference to N = 2048, with an SE from the scatter between realizations;
  - a weighted fit d_N = a + c·N^(−p) over N ≥ 32, or N ≥ 64 if the N = 32 point does not fit
    (χ²_red > 10). The order p comes from (a): 4, and 2 for Chua. The constant a absorbs the
    reference's own noise, which is common to every N.
- **Pass rule.** A criterion passes at N when two conditions hold:
  - the fitted bias is inside the tolerance at 95 % (|c·N^(−p)| + 2 SE);
  - the measured shift, relative to the fitted N → ∞ value, does not exceed the tolerance by more
    than 2 SE.

  Below the fit range the measured value alone must pass at 95 %. N_min is the smallest N such
  that it and every larger N pass at all three knob positions.

## Results

### (a) Order of the method and one-period error

|---|---|---|---|---|---|---|---|---|
| Lorenz | 2.1e-2 | 6.9e-4 | 2.2e-5 | 8.5e-7 | 4.9e-8 | 3.2e-9 | 1.3e-11 | 4.1 / 4.2 / 4.1 |
| Rössler | diverges | 1.8e-3 | 1.3e-4 | 9.0e-6 | 6.0e-7 | 3.8e-8 | 1.5e-10 | 4.0 / 3.9 / 3.8 |
| Chua | 9.4e-3 | 3.4e-3 | 2.1e-3 | 3.6e-4 | 6.6e-5 | 1.9e-5 | 9.9e-7 | **2.1 / 2.3 / 1.8** |
| Thomas | 2.5e-2 | 1.8e-3 | 1.2e-4 | 7.1e-6 | 4.4e-7 | 2.8e-8 | 1.1e-10 | 4.0 / 4.0 / 4.0 |
| Duffing | 4.7e-3 | 2.2e-4 | 1.1e-5 | 6.2e-07 | 3.6e-8 | 2.2e-9 | 8.2e-12 | 4.1 / 4.1 / 4.1 |

- **Order.** RK4 shows its order 4 on the four smooth systems.
- **Chua converges at order 2.** Its diode h(x) is piecewise linear, so F is only C⁰ at |x| = 1.
  An RK4 step that straddles a breakpoint makes an O(h²) error, and there are O(1) crossings per
  period. At N = 256 Chua's one-period error is 1e-4 σ, against 4e-8…1e-5 σ for the others (worst
  u: Rössler at u = 1, 1e-5 σ).
- **All are tiny in audio terms.** Even 1e-4 σ is an error signal 80 dB below the box's own level.
  For comparison, the spec deliberately kicks each box's initial condition by 1e-6 σ.

### Stability floor

Rössler diverges at N = 16 at every u (8/8 runs) and at N = 32 at u = 1 (8/8).

- **Cause: the z spike.** After a spike, z relaxes at rate c − x. RK4 is unstable for
  h·(c − x) > 2.79, which gives N_stab = P·max(c − x)/2.79.
- **Measured on the attractor.** max(c − x) = 14.8 at the default gives N_stab ≈ 31. At u = 1
  (c = 8.8), max(c − x) = 22.8 gives N_stab ≈ 49.
- **Other systems.** None diverges even at N = 16.

¹ At Chua u = 1 the catalog's own estimator, the peak centroid, is unstable. Its spread between
realizations is 10 ct per 10 000-period record, and the 8 reference runs average 15 ct away from the
others. It cannot resolve 1 ct at any N. The return time (spread 3.5 ct) shows the clean N⁻² trend
instead. Its fitted bias is −0.3 ct at N = 128 and −0.07 ct at 256. The centroid fit gives
−0.1 ± 0.4 ct at 128.

² Thomas at u = 1 is a stable periodic orbit (catalog λ·P = 0.003; σ identical between realizations
to 1e-5). From N = 64 on, the error is deterministic and falls as N⁻⁴. At N = 32, every run lands
on a different, coexisting attractor (σ −54 %, +335 ct), although N = 16 does not.

- **The range ends set the requirement, not the default.** At the default every system meets all
  three criteria at N = 64, except Chua's pitch (128). Nine of the ten range ends lie next to a
  periodic window, a crisis or a period jump, because that is where `select_chaotic_range` (and
  the trimming after the table pass) stops. The only exception is Lorenz's lower end, the end of
  the candidate range. The O(h⁴) change of the vector field caused by
  RK4 acts like a small parameter shift, and near such a boundary it can switch the attractor.
  Thomas at u = 0 (λ·P = 0.13) shows this: at N = 32 and 64 the numerical attractor is much more
  periodic (prominence +28 percentage points, pitch +17…+21 ct). From N = 128 on it is back.
  Rössler's stability floor is also set at u = 1.
- **σ.** At N ≥ 128 no σ error exceeds 0.5 %. The largest values, at the ends of the ranges, are
  −0.36 ± 0.20 % (Rössler σ_z, u = 1) and −0.37 ± 0.23 % (Thomas σ_z, u = 0), both within 2 SE of
  zero. The statistical floor (1 SE) is 0.02–0.36 %; Duffing's well-hopping is the noisiest.
- **Spectral envelope.** At N ≥ 128, every band above the −90 dB floor is within 0.2 dB at every u.
  The 10–20 f₀ band is within 0.2 dB from N = 64 on, and within 0.6 dB already at N = 32. Its
  level relative to the total is −43 to −97 dB (Duffing −110 to −144 dB). The envelope is therefore the least demanding criterion.
  The exception is Thomas at u = 0 and 1 at N ≤ 64, where the attractor itself changes, as above.
  A strict variant that also judges the inaudible bands (down to −172 dB) only changes Lorenz
  (128 instead of 16), whose bands below −130 dB are noise-limited.

### Cost

RK4 sub-steps per sample with the engine's rule (`Dynamical.substeps_per_sample`, fs = 48 kHz), at the
default (C8: maximum over u):

| N_cat | A4: Lorenz / others | A6: Lorenz / others | C8: Lorenz / others | Naive ⌈N·f₀/fs⌉ at A4 |
|---|---|---|---|---|
| 64 | 2 / 1 | 5 / 3 | 11 / 6–7 | 1 |
| 128 | 3 / 2 | 9 / 5–6 | 22 / 12–14 | 2 |
| 256 (now) | 5 / 3 | 17 / 10–11 | 43 / 23–28 | 3 |

- **Lorenz costs more than the formula says.** Its h_max is set by P_min = P(u=1) = 0.44, but the
  default runs at P = 0.76. It therefore takes 1.73× more sub-steps (N_eff = 545 at A4) than
  ADR 0006's "⌈N·f₀/fs⌉ whatever the system".
- **Low notes cost the same at any N.** Below f₀ ≈ fs·P_min/(N·P) the cost is one sub-step per
  sample whatever N is: about 375 Hz at N = 128 and 188 Hz at N = 256 (P ≈ P_min).
- **High notes scale with N.** The cost grows linearly with N, so halving N halves the work there.
- **Total cost.** It is RK4 work per box. Python renders about 10× faster than real time, so cost is
  not the bottleneck today; it may become one in the browser engine with many boxes at high notes.

### Side finding: the catalog's own period error is larger than any integration error

The long references (8–16 × 10 000 periods) give P at the default and at u = 1. The table shows
1200·log₂(P_catalog/P_reference), the detuning of a box tuned with the catalog's P(u) (one
2000-period record). Positive means the box sounds sharp.

| | Lorenz | Rössler | Chua | Thomas | Duffing |
|---|---|---|---|---|---|
| Default | −3.4 ct | 0.0 ct | −3.8 ct | **+11.7 ct** | exact |
| u = 1 | +0.5 ct | +2.7 ct | **+29 ct** | +0.1 ct | exact |

Spread of the period estimate between 10 000-period records: Thomas 2.5–3.9 ct and Chua at u = 1
10 ct (Lorenz ≤ 0.9 ct). These are the known "realization-dependent" Thomas and Lorenz tuning errors.
At N ≥ 128 they exceed the fitted integration bias by 10 to 1000 times.

## Conclusion

- **N = 256 is sufficient** everywhere, and **about 2× more than needed**. The strictest systems
  need 128: Rössler for RK4 stability and accuracy at the top of its range, and Chua because the
  piecewise-linear diode lowers RK4 to order 2. Thomas needs 128 to stay on the right attractor at
  u = 0. Whether 128 also keeps Thomas within 1 ct there is unresolved: it is below the realization
  noise, and the fit only confirms it at 256. Lorenz and Duffing need only 64.
- **256 is not "far more accurate than audio needs"** in the sense of `integrate.py`'s docstring.
  The margin is a factor of 2–4 in N, and at the ends of the ranges the binding effects are
  attractor changes and stability, not the smooth N⁻⁴ error.

**Uncertainties.**

- The 1-cent test is at or below the statistical floor for Thomas (any u), for Chua at u = 1 and for
  Rössler at u = 1. There the verdicts rest on the fitted N⁻ᵖ scaling, which assumes asymptotic
  behavior; Thomas at N ≤ 64 is clearly non-asymptotic.
- Only static parameters and pitch lock as in the catalog were tested. Audio-rate modulation was
  not tested, nor arithmetic below float64.
- N_eff in the engine is ≥ N_cat. The real margin at most knob positions and notes is therefore
  larger than in these tests, up to 1.9× for Lorenz.

## Recommendations

1. **Keep 256 as the global default unless CPU matters, then set it per system.** When CPU
   matters (browser engine, many boxes, high notes), use `steps_per_period = 128` for Lorenz,
   Rössler, Chua and Duffing, and keep 256 for Thomas. That cuts the RK4 work by 33–50 % (A4: Lorenz 5 → 3 sub-steps,
   the others 3 → 2). `BuildSettings.steps_per_period` is a single global value today, so per-system
   values need a small change in the catalog builder.
2. **Never go below 64** for any system. Rössler's stability limit is N ≈ 49 at u = 1, and Thomas
   changes attractor at N ≤ 64 at both ends of its range.
3. **Spend the effort on period estimation instead.** For pitch accuracy, longer or repeated catalog
   records for Thomas and Chua (near u = 1) buy far more than finer steps.
4. **Check any new or replacement system with this script.** Range ends close to windows, and
   non-smooth right-hand sides, are where the requirement comes from.
5. **Update ADR 0006, item 4.** h_max uses the shortest P over the range, so the cost is
   ⌈N·(P(u)/P_min)·f₀/fs⌉, not ⌈N·f₀/fs⌉ for every system (Lorenz takes 5 sub-steps at A4, not 3).
6. **Optionally, smooth Chua's diode** (for example a smooth |·| approximation of width ≪ 1) to
   restore order 4. This is an owner decision, because it changes the system's definition.
